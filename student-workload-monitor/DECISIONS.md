# Лог архитектурных и технических решений

## 1. Фиксация SDK .NET 9.0 для всей команды
* **Проблема:** Участники команды используют разные версии Visual Studio и пакеты EF Core (`Npgsql` 9.0.4 vs `Tools` 10.0.15), что вызывает конфликт зависимостей.
* **Решение:** В корень репозитория добавлен `global.json`, фиксирующий SDK версии `9.0.100` (`latestFeature`), а версии пакетов EF Core выровнены на `9.0.4`.

## 2. Статический анализ кода на уровне решения
* **Проблема:** Необходимо обеспечить отсутствие критических/мажорных замечаний линтера на 1000 строк кода (критерий C4).
* **Решение:** Добавлены `Directory.Build.props` (`EnableNETAnalyzers=true`, `AnalysisLevel=latest-recommended`) и `.editorconfig`.

## 3. Глобальная обработка исключений и битых JSON
* **Проблема:** Некорректные JSON или внутренние сбои могут приводить к утечке StackTrace или некорректным ответам API (критерий C2).
* **Решение:** Реализован `GlobalExceptionHandler` через `IExceptionHandler` (.NET 9) с возвратом `ProblemDetails` (RFC 7807) и настройкой `InvalidModelStateResponseFactory`.
